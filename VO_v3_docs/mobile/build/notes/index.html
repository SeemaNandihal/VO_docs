Notes

  1. To access the Notes feature, users must sign into (1) VachanOnline.com. ( See how to Sign In )

  2. The user must select the Bible Language (2), Bible book and chapter (3) by using the drop-down menus.

  3. The user can click on any verse (4) for which they wish to make notes and then select Notes Icon (5). A pop-up window for taking notes appears.

  1. Notes can be taken by the user (6) and saved (7) for later use.

It includes a rich text editor for formatting text, adding media, and customizing documents with fonts and colors.

  1. When notes for a verse have been saved, the Notes icon shows before the verse (8).
  1. A pop-up dialogue box will appear when the user click the note icon.

To access the Notes created earlier the user must click on the My Library icon (9) and select Notes (10).

The list of verses with notes are shown in the bottom pane. The user can click on any verse (11) to view its Bible text.

The note can be edited and after editing it the user can save the changes or close without saving the changes by clicking cancel.Using the delete icon , the notes can be deleted.

The Notes can be accessed from the Home page. Click the Sign In (1) avatar and select Profile (2).

The Profile page displays a list of Bookmarks, Notes(3), and Highlights . Click a reference (4) to navigate to the corresponding chapter on the Bible page.
