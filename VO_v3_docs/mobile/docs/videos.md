# Videos

Videos can be accessed from the home page. To view them, select **Video card (1)** from Everything you need to Grow section.

<img src="/img/assets/version3/videos1.png"  width="400px" alt="videos1" className="img-border"/>

- The Videos page allows users to search and filter Bible-related videos.  

- Use the **Language (2)** dropdowns to filter videos by language  

- Select **All Books (3)** to view videos from all available books.

- Use the **Search field (4)** to search by Bible book or video title.

<img src="/img/assets/version3/videos2.png"  width="400px" alt="videos2" className="img-border"/>

- The video count is displayed above the results. 

- Each video is shown as a card with a thumbnail, category, and title.  

- Click a video card to open the video player, where you can play, pause, seek, adjust volume, and use full-screen mode. 

- Filters can be combined to narrow the available videos. 


While on the **Read Bible** page, the user can access the **Video** panel. 

<img src="/img/assets/version3/videos3.png"  width="400px" alt="videos3" className="img-border"/>

- To access Videos, open the Read Bible page,click study tools,  click **More Tools (1)**, and select **Videos (2)**. 

- Select the required **language (3)** and **book and chapter (4)** on the Read Bible page. 

- The Videos panel automatically updates to display videos related to the selected content. 

- The available videos are displayed as video cards, with each card showing a title and thumbnail. 

- Click a video card to open  

- From the menu that appears in the bottom pane **(4)**, the user can select the languages in which they want to view the video.
