# Bible Stories

To access Bible stories, click on the **Bible Stories card (1)** on the home page.
 
<img src="/img/assets/version3/biblestories.png"  width="400px" alt="biblestories" className="img-border"/>

### Stories in Indian Sign Language

Bible stories are now available in Indian sign language.

1. The story must be chosen from the stories drop-down menu **(2)**
2. Select the Story **(3)**

<img src="/img/assets/version3/ISL1.png"  width="400px" alt="ISL1" className="img-border"/>

3. Click on the play button **(4)**
3. A description of the story can be viewed by clicking the downward pointing arrow **(5)**

<img src="/img/assets/version3/ISL2.png"  width="400px" alt="ISL2" className="img-border"/>


### Text versions of stories

1. To access Bible stories, click on the **Bible Stories card (1)** on the home page.

<img src="/img/assets/version3/biblestories.png"  width="400px" alt="biblestories" className="img-border"/>

2. The language drop-down menu **(2)** allows the user to select the desired language 

3. The user can now select the desired stories by scrolling through the available stories **(3)**.

<img src="/img/assets/version3/biblestories1.png"  width="400px" alt="biblestories1" className="img-border"/>

4. The user has the option to adjust the font size by clicking fonts icon **(4)**

<img src="/img/assets/version3/biblestories2.png"  width="400px" alt="biblestories2" className="img-border"/>

5. Click Cancel **(5)** to exit the Stories section.
