# Audio 

<img src="/img/assets/version3/studytools.png"  width="400px" alt="studytools" className="img-border"/>

To access all the available Audio Bibles, on the Read Bible page you must Select the **Study Tools (1)** and select **Audio(2)**.

- There is an option to select the **language (3)** for the Audio Bible in the right pane.

- Select the Bible **book and chapter (4)** from the Left bible panel drop-down menu.

- To listen to the Audio Bible, the user must click the **play button (6)**.

<img src="/img/assets/version3/studytool_audio.png"  width="400px" alt="study_audio" className="img-border"/>

- The **volume (7)** adjusted using the settings.

- Users can adjust the **Playback Speed (8)** from 0.5× to 2×. 


<img src="/img/assets/version3/studytools_audio1.png"  width="400px" alt="study_audio1" className="img-border"/>

- The **Sleep Timer (9)** can be set to 5 minutes, 10 minutes, 15 minutes, 30 minutes, or 1 hour, or turned Off.
