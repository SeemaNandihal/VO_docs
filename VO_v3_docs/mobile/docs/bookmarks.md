# Bookmarks

1. The users must be **Signed In** to **(1)** VachanOnline.com to bookmark a chapter.                        ( [See how to Sign In](./signIn) )

2. The User can click the **Bookmarks** icon **(2)** while reading the Bible from the reading pane.

<img src="/img/assets/version3/bookmark1.png"  width="400px" alt="bookmark1" className="img-border"/>

3. The chapter will be bookmarked for future reference. The **Bookmarks** icon **(2)** changes to black, once the chapter has been bookmarked.

<img src="/img/assets/version3/bookmark2.png"  width="400px" alt="bookmark2" className="img-border"/>

4. To access the previously bookmarked chapters, the user has to click on the **My Library icon (3)** on the Read Bible page and select **Bookmarks (4)**. 

<img src="/img/assets/version3/bookmark3.png"  width="400px" alt="bookmark3" className="img-border"/>

5. On selecting the Bookmarks option from the menu, the Bookmarks Panel opens. The user can select any **reference (5)** they wish to continue reading. The reference that has been selected opens in **Read Bible page (6)**. 

6. The bookmarked chapter may be deleted..   

7. The user must click the close icon to close the **Bookmarks** page and go back to the Study Bible page.  

<img src="/img/assets/version3/bookmark3.png"  width="400px" alt="bookmark3" className="img-border"/>

The Bookmarks can be accessed from the Home page. Click the **Sign In (1)** avatar and select **Profile (2)**.

<img src="/img/assets/version3/signinavatar.png"  width="400px" alt="signinavatar" className="img-border"/>

The Profile page displays a list of **Bookmarks (3)** , Notes, and Highlights. Click a **reference (4)** to navigate to the corresponding chapter on the Bible page.

<img src="/img/assets/version3/bookmark4.png"  width="400px" alt="bookmark4" className="img-border"/>
