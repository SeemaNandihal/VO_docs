# About
## The Vachan Project
Upon clicking the **About Us** **(2)** button in the bottom bar on the Landing Page, a dialog box will appear, providing information about the Vachan Project and its development.


<img src="/img/assets/version3/homepage5.png"  width="400px" alt="homepage5" className="img-border"/>

## What's New
Updates and improvements for the previous three releases can be viewed in the what's new **(3)** tab. It also has a link to assist users in navigating the website and a list of all the features.


## Feedback
A **Feedback form(4)** is offered to collect valuable feedback from the Vachan online users and to have a better idea of the overall user experience. 


## VachanOnline Classic 

Tap **VachanOnline Classic (5)** to navigate to the older version of the Vachan Online website. This option allows users to access the classic website and continue using its existing interface and features.

## Contact Us
The user can also email us at thevachanproject@bridgeconn.com with their questions, concerns and suggestions.

We are happy to receive your feedback!

Please visit our website at https://vachanonline.com to use the features explained above.
