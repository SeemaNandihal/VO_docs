# Parallel Bible

The Parallel Bible feature allows you to read and compare two Bible versions simultaneously.

<img src="/img/assets/version3/studytools.png"  width="400px" alt="studytools" className="img-border"/>

- To access the Parallel Bible, click **Study Tools (1**) on the Read Bible page and select the **Parallel Bible** .

<img src="/img/assets/version3/parallelbible.png"  width="400px" alt="parallelbible" className="img-border"/>

- Use the **Language and Version drop-down (3)** to select the preferred language and Bible version.

- Select the desired book and chapter from the **Book drop-down menu (4)**.

- The Parallel Bible automatically synchronizes the book, chapter, and scroll position, when available.

- To read the two Bible versions independently, click the **Parallel Scroll icon (5)** in the middle of the page to disable synchronization.

- If no book is available in the parallel pane, Parallel Scroll is disabled and a warning message is displayed.

- Click the **Close icon (6)** to close the Parallel Bible view and access the other study tools.
