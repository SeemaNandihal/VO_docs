# Infographics

Infographics can be accessed from both the [menu](./websiteNavigation#menu-with-various-features) on the home page and the Study Bible page. To access Infographics select **Infographics** from the menu. All the cards will be visible on one page.

After the Infographics cards appear, the user can choose the language **(1)** for viewing and search **(2)** for specific cards by entering the card name in the search input box.

<img src="/img/assets/menuinfo.png" width="500px" alt="menuinfo" className="img-border" />


Follow these steps to access the Infographics from the Study Bible page:

1. To read, understand, visualize and study the Bible through images and visual supports, the user should click on the [Drawer Menu](./studyBible#drawer-menu) and select **Infographics**. 

2. The user has the option to choose the language **(1)**  and the Bible book from the drop-down menu **(2)**. 

3. If the book has Infographics, it will appear on the screen.  

<img src="/img/assets/info1.png" width="500px" alt="info1" className="img-border" />

4. The user can click on a card to enlarge the image in it. 

<img src="/img/assets/info2.png" width="500px" alt="info2" className="img-border"  />

5. Once the image is enlarged the user can rotate, zoom in or out, and navigate to the next and previous images by choosing the options listed below the image **(3)**.
