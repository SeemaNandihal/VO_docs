# Compare 


The **Compare** feature allows users to enhance the understanding of verses by displaying them in various translations. Here's how to utilize it.

1. On the Homepage, click the **Compare Card (1)**.

<img src="/img/assets/version3/compare.png"  width="400px" alt="compare" className="img-border"/>

2. The user can select up to **four languages (2)** for verse comparison **(2)**.

<img src="/img/assets/version3/compare1.png"  width="400px" alt="compare1" className="img-border"/>

3. The user can pick the book and chapter **(3)** and verse **(4)** they want from the drop-down menu

4. Click on the version the user wants to read **(5)**.

6. The user can use the arrows to move to the previous **(6)** or next **(7)** verses.
