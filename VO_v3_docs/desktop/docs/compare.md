# Compare 

The **Compare** feature can be accessed from the Home Page by selecting the Compare card (1). This opens the Compare page, where users can view and compare the available Bible versions or resources.

<img src="/img/assets/Versionv3/compare.png"  width="1000px" alt="compare"/>

Here's how to use it:

1. Open the Compare page by selecting the Compare card on the Home Page.

<img src="/img/assets/Versionv3/compare1.png"  width="1000px" alt="compare1"/>

2. The user can pick the book and chapter **(1)** and verse **(2)** they want from the drop-down menu

3. Users can select up to four languages for comparison **(3)**.


4. The user can use the arrows to move to the previous **(5)** or next **(4)** verses.

5. Click on the version the user wants to read **(6)**.


6. To return to the Read Bible page click the **Vachan Logo (7)**.

**To access the Compare feature from the Read Bible page, select any verse (1) to open the Highlight pop-up, then select the Compare icon (2).**
