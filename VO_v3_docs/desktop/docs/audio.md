# Audio 

<img src="/img/assets/Versionv3/audio2.png"  width="1000px" alt="navigation"/>


To access all the available Audio Bibles, on the Read Bible page you must Select the Study Tools and select **Audio(1)**.

- There is an option to select the **language (2)** for the Audio Bible in the right pane.

- Select the Bible **book and chapter (3)** from the Left bible panel drop-down menu.

- To listen to the Audio Bible, the user must click the **play button (4)**.

- The **volume (5)** adjusted using the settings.

- Users can adjust the **Playback Speed (6)** from 0.5× to 2×. 

- The **Sleep Timer (7)** can be set to 5 minutes, 10 minutes, 15 minutes, 30 minutes, or 1 hour, or turned Off.
