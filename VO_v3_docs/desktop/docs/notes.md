# Notes

To access the **Notes** feature, users must sign into **(1)** VachanOnline.com. ( [See how to Sign In](./signIn) )

The user can select the **Bible language (2)**, **Bible book and chapter (3)** by using the drop-down menus.

The user can click on any verse **(4)** for which they wish to make notes and then select **Notes** Icon **(5)**. A pop-up window for taking notes appears.

The user can take notes **(6)** and save **(7)** them for future reference.

It includes a **rich text editor** for formatting text, adding media, and customizing documents with fonts and colors.

<img src="/img/assets/Versionv3/notes1.png"  width="1000px" alt="notes1"/>

To access the notes the user must select the **My Library (8)** and select **notes (9)** from the menu.

<img src="/img/assets/Versionv3/notes2.png"  width="500px" alt="notes2"/>

When notes for a verse have been saved, the Notes icon shows after the verse **(10)**. By clicking on the Notes icon, the user can access the Notes panel.

<img src="/img/assets/Versionv3/notes3.png"  width="1000px" alt="notes3"/>

The notes for the current chapter appear on the top as a separate section.

The list of verses with notes are shown in the right pane. The user can click on any verse **(10)** to view its Bible text.
  
The Notes can be accessed from the Home page. Click the **Sign In (1)** avatar and select **Profile (2)**.

<img src="/img/assets/Versionv3/signinavatar.png"  width="400px" alt="signinavatar"/>

The Profile page displays a list of Bookmarks, **Notes(3)**, and Highlights . Click a **reference (4)** to navigate to the corresponding chapter on the Bible page.

<img src="/img/assets/Versionv3/notes4.png"  width="1000px" alt="notes4"/>
