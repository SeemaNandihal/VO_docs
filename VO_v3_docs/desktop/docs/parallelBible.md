# Parallel Bible

The Parallel Bible feature allows you to read and compare two Bible versions simultaneously.

-To access the Parallel Bible, click Study Tools on the Read Bible page and select the **Parallel Bible (1)**.

<img src="/img/assets/Versionv3/parallelbible1.png" width="1000px" alt="parallelbible" />

- Use the **Language and Version drop-down (2)** to select the preferred language and Bible version.

- Select the desired book and chapter from the **Book drop-down menu (3)**.

- The Parallel Bible automatically synchronizes the book, chapter, and scroll position, when available.

- To read the two Bible versions independently, click the **Parallel Scroll icon (4)** in the middle of the page to disable synchronization.

- If no book is available in the parallel pane, Parallel Scroll is disabled and a warning message is displayed.

- Click the **Close icon (5)** to close the Parallel Bible view and access the other study tools.
