# Bookmarks

The users must be **Signed In** to **(1)** VachanOnline.com to bookmark a chapter. ( [See how to Sign In](./signIn) )

The Langauage **(2)** and book **(3)**  should be selected from the drop-down. The User can click the **Bookmarks** icon **(4)** while reading the Bible from the reading pane.

The chapter will be bookmarked for future reference. The Bookmarks icon **(4)** changes to black, once the chapter has been bookmarked.

<img src="/img/assets/Versionv3/bookmark1.png"  width="1000px" alt="bookmark1"/>

To access the previously bookmarked chapters, click on the My Library icon **(5)** and select Bookmarks **(6)**.

<img src="/img/assets/Versionv3/bookmark2.png"  width="1000px" alt="bookmark2"/>

The **Bookmarks** pane opens on the right side of the Bible page and displays all bookmarked chapters. 
To open a bookmarked chapter, click any reference **(5)**. The Bible opens to the selected chapter. You can delete **(6)** bookmarks whenever needed.


<img src="/img/assets/Versionv3/bookmark3.png"  width="1000px" alt="bookmark3"/>

The Bookmarks can be accessed from the Home page. Click the **Sign In (1)** avatar and select **Profile (2)**.

<img src="/img/assets/Versionv3/signinavatar.png"  width="400px" alt="signinavatar"/>

The Profile page displays a list of **Bookmarks (3)** , Notes, and Highlights. Click a **reference (4)** to navigate to the corresponding chapter on the Bible page.

<img src="/img/assets/Versionv3/bookmark4.png"  width="1000px" alt="bookmark4"/>
