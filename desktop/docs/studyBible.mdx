# Study Bible
The Study Bible is accessible through the [Menu](./websiteNavigation#Menu) on the homepage as well as from the Study Bible index.

When the user accesses the **Study Bible Page** they will be directed to the Study Bible page shown below.
<img src="/img/assets/studybiblepage.png"  width="1000px" alt="studybible"/>

1. There is a Menu on the right side **(1)**, which allows the user to access the following features: [Search Bible](./searchBible), [Parallel Bible](./studyBible#parallel-bible), [Commentaries](./commentaries), [Sign Language Bible](./signLanguageBible), [Infographics](./infographics), [Audio Bibles](./audioBible), [Videos](./videos), [Reading Plans](./readingPlans), [Dictionaries](./dictionaries), [Bookmarks\*](./bookmarks), [Highlights\*](./highlights), [Notes\*](./notes). The user can also view their browsing history by clicking on the **History** icon.
2. The Bible reading page shows one chapter at a time. There are drop-downs to select the language **(2)** and book **(3)** on the upper left side. Here, the users can select their preferred Language, Version, Book and Chapter.
3. There are arrows on either side of the biblical text, Next **(4)** and Previous **(5)**, which can be used to move between chapters.

4. The user can get back to the landing page by clicking the Vachan Online logo **(6)** in the top left corner.
5. To access various features from the landing page, click on the [Menu](./websiteNavigation#Menu) **(7)**.

**\* Note:-** [Bookmarks](./bookmarks) , [Highlights](./highlights) and [Notes](./notes) feature required the user to [Sign In](./signIn) on VachanOnline

The users can study the Bible of their choice in **single view** and **parallel view**.
## Single Pane View

**To access the Bible and start reading, the user should follow these steps on the study bible page.**

- On the Study Bible page choose the desired language and version from the version drop-down menu **(1)**.

- Select the Book and chapter from the book drop-down menu **(2)**.

<img src="/img/assets/singleview.png" width="1000px" alt="singleview" />

On the study bible page, the user has the options to take notes, highlight verses, bookmark chapters, go to compare versions, share the chapter with others and access to other features **(3)**.

**\* Note:-** [Bookmarks](./bookmarks) , [Highlights](./highlights) and [Notes](./notes) features require the user to Sign Up on VachanOnline.

Visit [Settings](./readBible#Settings) to learn more.

## Parallel Bible

To utilize the Parallel Bible feature and read multiple versions at the same time, the user can follow these steps:

Click on the **Parallel Bible** icon **(1)** located on the right menu to open the Parallel Bible view.

Use the version drop-down **(2)** to select the desired language and version for simultaneous viewing of the Bible in two languages.

When the Parallel Bible view opens, it will automatically synchronize the Bible book, chapter, and scroll position, if available.

If the user prefers to read from the Parallel Bible independently, they can disable this synchronization by clicking on the Parallel Scroll icon **(3)** located in the middle of the page.

The Parallel Scroll is disabled, if there is no book in the parallel pane and it shows a warning message once it is disabled.
