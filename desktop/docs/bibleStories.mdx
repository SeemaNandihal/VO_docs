# Bible Stories

**Accessing Bible Stories** 

- Open the VachanOnline landing page. 

- Locate the Bible Stories card. 

- Click Bible Stories. 

- The Bible Stories page opens. 

### Bible stories in Indian Sign language

<img src="/img/assets/Versionv3/biblestoriesisl.png"  width="1000px" alt="biblestories"/>

The stories are now available in Indian Sign Language. The user must choose **Indian sign Language** from the drop-down **(1)** menu in order to view the stories and select the stories **(2)**. 

The selected story opens in a story viewer.

Click on the play button  **(3)** to watcth the videos. 

Video description is accessible by clicking the downward pointing arrow **(4)**.

<img src="/img/assets/Versionv3/biblestoriesisl1.png"  width="1000px" alt="biblestories"/>


### Text version of stories

Open the VachanOnline landing page, locate and click the **Bible Stories card** to open the Bible Stories page.

<img src="/img/assets/Versionv3/biblestories1.png"  width="1000px" alt="biblestories"/>

The language drop-down menu **(1)** allows the user to select the desired language.

The user can now choose the desired stories from the cards **(2)**.

The selected Bible Story can be seen in the story viewer **(3)**. Beautiful visuals have been used to illustrate the story.

The user has the option to adjust the font size by clicking on **fonts icon (4)**.

Click the **Cancel icon (5)** to exit the story viewer.

<img src="/img/assets/Versionv3/biblestories2.png"  width="1000px" alt="biblestories"/>
