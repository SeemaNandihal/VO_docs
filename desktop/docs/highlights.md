# Highlights

The users must have **Signed In** to **(1)** VachanOnline.com to use the **Highlights** feature. ( [See how to Sign In](./signIn) )

The user can select the Bible Languag  **(2)**, Bible book and chapter **(3)**by using the drop-down.

The user can click on any verse they want to highlight **(4)** and then select Highlights **(5)** and highlight using any of the available colors. 

The verse will be highlighted for future reference. To remove the highlights click on clear icon **(6)**.

<img src="/img/assets/Versionv3/highlights.png"  width="1000px" alt="highlights"/>


To access the previously highlighted verses, click on the My Library icon **(7)** and select Highlights **(8)**.
The list of highlighted verses appears on the right pane.

<img src="/img/assets/Versionv3/highlights1.png"  width="1000px" alt="highlights1"/>

The user can select any verse **(9)** they wish to read. The verse **(9)** that has been selected opens in the study bible page.
You can delete **(10)** bookmarks whenever needed.

<img src="/img/assets/Versionv3/highlights2.png"  width="1000px" alt="highlights2"/>

The **Highlights** can be accessed from the Home page. Click the **Sign In (1)** avatar and select **Profile (2)**. 

<img src="/img/assets/Versionv3/signinavatar.png"  width="400px" alt="signinavatar"/>

The Profile page displays a list of Bookmarks, Notes, and **Highlights (3)**. Click a **reference (4)** to navigate to the corresponding chapter on the Bible page.

<img src="/img/assets/Versionv3/highlights4.png"  width="1000px" alt="highlights4"/>
