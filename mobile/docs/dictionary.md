# Dictionary

To access the **Dictionary**, open the Read Bible page, select Study Tools, and click **More Tools (1)** in the tools panel. Then, select **Dictionary** from the menu. 

The Dictionaries can be selected from the drop-down menu **(2)**.

<img src="/img/assets/version3/dictionary.png"  width="400px" alt="dictionary" className="img-border"/>

Users must select the dictionary language **(3)**.

Currently, the dictionary is available in English and Hindi. 

Select the dictionary word you want to study from the drop-down menu **(4)**.

The selected word’s definition, synonyms and references appear along with the Strong's numbers associated with the word.
