# Highlights

1. The users must have **Signed In** to **(1)** VachanOnline.com to use the **Highlights** feature. ( [See how to Sign In](./signIn) )

2. The user can select the Bible Language **(2)**, Bible book and chapter **(3)** by using the drop-down menus. 
3. The user can click on any verse they want to highlight **(4)** and highlight using any of the available colors **(5)**.
4.  The verse will be highlighted for future reference. 
5.  To clear the portions highlighted earlier, select the verses **(4)** and use the clear icon **(6)** to remove the highlights from the selected verses. 
6.  To close the bottom toolbar click the close button **(7)**.  

<img src="/img/assets/version3/highlights1.png"  width="500px" alt="highlights1" className="img-border"/>

To access the previously highlighted verses, navigate to **My Library (8)** on the Read Bible page and select **Highlights (9)**.

<img src="/img/assets/version3/highlights2.png"  width="500px" alt="highlights2" className="img-border"/>

The list of the previously highlighted verses appear in Highlights panel.

1. The user can select any verse **(10)** they wish to read. 
   
2. The verse  that has been selected opens in the **Read Bible page (11)**. 
   
<img src="/img/assets/version3/highlights3.png"  width="500px" alt="highlights3" className="img-border"/>

The **Highlights** can be accessed from the Home page. Click the **Sign In (1)** avatar and select **Profile (2)**. 

<img src="/img/assets/version3/signinavatar.png"  width="500px" alt="signinavatar" className="img-border"/>

The Profile page displays a list of Bookmarks, Notes, and **Highlights (3)**. Click a **reference (4)** to navigate to the corresponding chapter on the Bible page.

<img src="/img/assets/version3/highlights4.png"  width="500px" alt="highlights4" className="img-border"/>
