# Study Bible

The Study Bible is accessible through the [Menu](./websiteNavigation#menu-with-various-features) on the homepage as well as from the Study Bible index.

### Top navigation bar
On the Study Bible page, the user has access to various features.

<img src="/img/assets/studybibletopnavigation.png"  width="300px" alt="topnavigation" className="img-border "/>

1. By clicking at **(1)**, the user can access [menu](./websiteNavigation#menu-with-various-features) with features
2. Clicking on the vachan logo the user can go back to Home page**(2)**
3. Share  **(3)**
4. Bookmarks **(4)** 
5. Settings with variety of options **(5)**
6. Clicking on the help icon **(6)** allows the user to access the user manual page for Study Bible.


### Bottom navigation bar
<img src="/img/assets/studybiblebottomnavigation.png"  width="300px" alt="topnavigation" className="img-border"/>

###
A number of features are accessible from the bottom navigation bar:
 [Parallel Bible](./studyBible#parallel-view), [Commentaries](./commentaries), [Reading Plans](./readingPlans), [Search Bible](./searchBible) and **Drawer menu (1)** with various features.

 The user can also view their browsing history by clicking on the history icon. 

### Drawer Menu
The user needs to click on the **Drawer menu (1)** to access [Commentaries](./commentaries), [ISLV Bible](./signLanguageBible), [Infographics](./infographics), [Audio Bible](./audioBible), [Videos](./videos), [Dictionaries](./dictionaries), [Bookmarks](./bookmarks),
[Highlights](./highlights), [Notes](./notes) and [History](./history).

<img src="/img/assets/drawermenu.png"  width="300px" alt="tdrawermenu"  className="img-border "/>

The users can study the Bible of their choice in **single pane view** and **parallel view**.

## Single Pane View

All additional features open within a single view from the study bible page.

To access the Bible and start reading, the user should follow these steps: 

1. Choose the desired language and version from the version drop-down menu **(1)**.

2. Select the Book and chapter from the book drop-down menu **(2)**.

<img src="/img/assets/studybible1.png" width="500px" alt="studybible1" className="img-border" />


3. On the Study Bible page, the user has the options to [Search Bible passage](./readBible#search-bible-reference), [Bookmark chapters](./bookmarks), choose the [font](./readBible#font-settings), go to compare versions, share the chapter with others and access to other features  **(3)**.

## Parallel View
To utilize the **Parallel Bible** feature and read multiple versions at the same time, the user can follow these steps: 

<img src="/img/assets/parallelbible1.png" width="500px" alt="parallelbible1" className="img-border" />


1. Click on the **Parallel Bible** icon **(1)** located at the bottom navigation bar.
2. Use the version drop-down **(2)** to select the desired language and version 
3. When the **Parallel Bible** view opens, it will automatically synchronize the Bible book, chapter, and scroll position, if available. 
4. The users can disable this synchronization by clicking on the parallel scroll icon **(3)** located at the top of the page. 
5. The user can click on the close button **(4)** in order to close the parallel view.
